# 🌍 Global Teen Social Media & Mental Health Risk Dashboard

## 📌 Project Overview
This project analyzes global teenage social media usage and its potential relationship with mental health, sleep patterns, cyberbullying, and digital wellbeing. The dashboard was developed using Microsoft Excel to explore trends, compare countries, and identify potential risk patterns.

## 🎯 Objectives
- Analyze teenage screen time and social media usage across countries.
- Explore mental health risk and digital wellbeing indicators.
- Compare cyberbullying and problematic social media usage rates.
- Identify countries with higher reported risk levels.
- Explore trends and forecasts from 2015 to 2060.

## 🛠️ Tools & Technologies
- **Microsoft Excel**
- Power Query for data cleaning and transformation
- Excel formulas and functions
- PivotTables and PivotCharts
- Interactive slicers and dashboard visualizations

## 📊 Key Performance Indicators (KPIs)
- Average Screen Time
- Average Mental Health Risk
- Average Digital Wellbeing
- Cyberbullying Rate
- Problematic Social Media Use Rate

## 📈 Dashboard Features
- Country-wise and region-wise comparisons
- Social media usage and screen time analysis
- Mental health risk analysis
- Cyberbullying and problematic usage insights
- Global risk rankings
- Year-wise trend analysis
- Interactive filters for exploring the data

## 📂 Dataset
The project uses five CSV files containing country-level profiles, yearly summaries, global risk rankings, forecasts, and detailed teenage social media behaviour data.

**Dataset coverage:** 2015–2060

**Note:** The dataset includes synthetic data. The findings are exploratory and should not be interpreted as clinically validated results or proof of causation.
